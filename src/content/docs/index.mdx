## Start here

:::tip[Recommended first step]

[Install the Custom Server mod](/guides/custom-server/) to set up UE4SS and enable the first documented Neodash runtime mod.

:::

This guide documents practical ways to inspect and modify Neodash. Begin with the Custom Server guide, then use the reference material to understand the game's files, engine version, and modding limits.

## Modding paths

### Runtime mods with UE4SS

Use [UE4SS](https://github.com/UE4SS-RE/RE-UE4SS) for Lua scripts, runtime inspection, and hooks. The CustomServer mod is the first walkthrough in this guide.

### Cooked asset overrides

Use classic UE4 Pak overrides to replace cooked assets without modifying the original game archive. Replacements must match the original Unreal package paths and be compatible with Neodash's engine version.

### Official creation tools

Neodash's built-in level editor and community browser remain separate from external modding. They are the supported tools for creating and sharing levels.
