## Game overview

**Neodash** is a fast-paced arcade racing game developed and published by
Axan Gray. Released on August 17, 2022, it challenges players to drift, steer,
and launch a vehicle across neon tracks while avoiding traps, gaps, and a world
that collapses behind them. Its environments react to an electronic soundtrack,
making timing, speed, and presentation part of the same experience.

## Modding baseline

Neodash includes an official level editor and community browser. External
modding in this guide focuses on two additional paths:

- **UE4SS** for runtime inspection, Lua scripting, and hooks.
- **Classic UE4 Pak overrides** for cooked-asset replacement.

The inspected game is based on Unreal Engine 4.26.2 and uses the internal
project name `Runway`. See [Game Findings](/reference/game-findings/) for the verified
engine and Steam build details, Pak structure, loose level format, runtime
components, user-data paths, and open questions that still need in-game testing.
